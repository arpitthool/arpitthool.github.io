# arpitthool.github.io

Personal academic website of **Arpit Thool** — Research Scientist at Adobe Research Engineering & Design (RED).

A static site (plain HTML/CSS) served by GitHub Pages at <https://arpitthool.github.io>.
There is no build step — edit `index.html` / `stylesheet.css` and push.

## Structure
- `index.html` — the page (bio, research/publications, experience, education, projects)
- `stylesheet.css` — styles
- `images/` — profile photo and publication thumbnails
- `data/` — CV / resume PDF
- `.nojekyll` — tells GitHub Pages to serve files as-is (no Jekyll processing)
